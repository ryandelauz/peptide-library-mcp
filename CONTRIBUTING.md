# Contributing

This repository holds documentation, client configuration examples and registry metadata for the hosted Peptide Library MCP server. The server code is maintained privately by Peptide Library.

Welcome contributions:

- Fixes to the setup instructions for a client (menus change often; say which version you tested).
- Configuration examples for MCP clients not covered yet.
- Reports of wrong or unclear tool output: open an issue with the tool name, the arguments and what you expected. Please don't include personal health information.

Data corrections (a fact in a peptide profile) go to Peptide Library directly, with the page URL and a supporting source: https://peptidelibrary.app/support.

Content rules the server follows, which contributions should not work around: no dosing or administration instructions, no vendors or prices, no ranking of peptides, and no invented citations.
