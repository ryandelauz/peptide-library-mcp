# ChatGPT

Where your plan or workspace allows custom MCP servers:

1. Open Plugins (https://chatgpt.com/plugins), select **+**, then **Add custom MCP server**.
2. Name `Peptide Library`, Server URL `https://peptidelibrary.app/mcp`.
3. Authentication: **No authentication**.
4. Accept the warning and select **Create as a plugin**.
5. In a chat, type `@` and choose Peptide Library.

Menu names change between ChatGPT releases; OpenAI's help center has the current steps.

Try: "@Peptide Library compare semaglutide and tirzepatide in a table."
